# PocketLog

A record of what you actually did with your time.

Log an activity, give it a duration, and leave. Everything else — the calendar, the
charts, the search — is derived from that. No account, no network, no telemetry.

## What it does

- **Log an activity** with a title, category, duration, start time, and an optional
  note. Quick capture logs a title against your default duration in one line.
- **Today** puts the day in order: a summary of the total, then each entry as a card
  with its category colour, time range, and a bar showing how long it took relative
  to the rest of the day.
- **Calendar** gives you the month as a grid with per-day density, plus the selected
  day's timeline beneath it.
- **Insights** charts where the time went — daily totals, category split, and how
  the week compares to the one before.
- **Search** finds any entry by title, note, or category.
- **Backup** by exporting or importing the whole log as JSON.

## Running it

Requires Node and npm.

```bash
npm install
npm start          # Metro; press a / i / w for Android, iOS, web
```

The app uses native modules — SQLite, Reanimated, Gesture Handler — so it needs a
**development build**, not Expo Go:

```bash
npm run android    # build and run on a connected device or emulator
npm run ios        # macOS only
```

Other scripts:

| Script | Does |
| --- | --- |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run lint` | ESLint via `expo lint` |
| `npm run doctor` | `expo-doctor` — dependency and config health |
| `npm run contrast` | WCAG AA check of every colour pair in the palette |
| `npm run export:android` | production JS bundle |

Run `typecheck`, `lint` and `contrast` before opening a PR.

## How it is put together

Expo Router, so every file in `app/` is a screen and `_layout.tsx` files are
navigators. Everything else lives in `src/`.

```
app/
  _layout.tsx            root stack, providers, snackbar host
  (tabs)/                Today, Calendar, Insights, Search
  (onboarding)/          first-run setup
  activity/[id].tsx      one activity in full
  settings.tsx
  dev/gallery.tsx        every UI primitive on one screen
src/
  components/            TabBar, AppErrorBoundary
    ui/                  the design-system primitives
  db/                    client, migrations, repositories, queries
  features/activity/     add/edit sheet and its form schema
  hooks/                 data access, mutations, today-key tracking
  lib/                   haptics, motion, formatting, ids, categories
  stores/                Zustand: settings, UI, db invalidation
  theme/                 tokens and the theme context
  types/                 Activity, Category
  utils/                 time parsing and formatting
scripts/                 contrast and brand-asset checks
```

### Data

SQLite via `expo-sqlite`, with migrations tracked in `PRAGMA user_version`. Two
tables: `categories` and `activities`, plus indexes on day, start time, and
(category, day) — day grouping is an indexed equality lookup rather than a range
calculation, so it stays correct even if the device timezone changes after an entry
is written.

Repositories own SQL and hand back hydrated rows; `src/db/queries.ts` wraps them in
observable queries so every screen re-reads after a mutation. Nothing polls.

### Destructive actions are undoable, not confirmed

Deleting an entry fires an undo snackbar rather than opening a dialog. The row is
re-inserted verbatim, with its original id and timestamps, so restoring it does not
lie about when it happened. Import is the one exception — it replaces the whole
table, and asks first.

## Design

Warm paper and ink, with a single burnt-vermelion accent that is the only saturated
colour in the app. Depth comes from hairline borders and one-step tonal surfaces
rather than shadows; only the add button and sheets actually cast one.

Type is Poppins and only Poppins. Seven categories, each with its own hue *and* its
own glyph, so nothing depends on colour discrimination alone. Every text/background
pair clears WCAG AA in both light and dark, which `npm run contrast` enforces against
the real token file.

## Notes

- `android/` and `ios/` are generated by Continuous Native Generation and are not
  committed. Configure native behaviour in `app.json` and config plugins.
- Icon, splash, and favicon are generated by `scripts/generate-assets.ps1` and
  verified by `scripts/verify-assets.ps1`.
- The day rolls over on a timer, not on app resume — see `src/hooks/useTodayKey.ts`.
